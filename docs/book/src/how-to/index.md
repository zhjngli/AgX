# How-to guides

Recipe-style guides for specific AgX tasks. Each one assumes you have AgX installed and you know what you want to accomplish — pick the page that matches your task.

Common tasks:

- [Apply a preset to a folder of photos](batch-apply.md) — `batch-apply` over a directory.
- [Compare looks side-by-side on one image](multi-apply.md) — `multi-apply` for preset audition.
- [Write your own preset](write-preset.md) — author a TOML preset from scratch.
- [Extend a preset](extend-preset.md) — build a variant on top of a base preset using `extends`.
- [Author a custom `.cube` LUT](custom-lut.md) — hand-write or generate a 3D LUT.
- [Compose layered looks](compose-looks.md) — stack presets at apply time using `--presets`.

If your task isn't here, check the [CLI reference](../reference/cli.md), the [preset reference](../reference/preset.md), or the [explanation pages](../explanation/index.md) for background.
